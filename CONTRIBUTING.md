# Contributing to RoboEyes

Thanks for your interest in contributing to RoboEyes – it's much appreciated!

## ⚠️ Pull requests are paused for now

A **new major version of RoboEyes is currently in development**. The internal architecture has changed significantly, so pull requests based on the current codebase would most likely no longer apply to the new version.

To save you time and effort, **please hold off on pull requests for the next few weeks** until the new version has been released. PRs opened in the meantime may be closed without merging – not because your work isn't valued, but because the code they touch will be replaced.

## What you can still do

- **Report bugs:** Feel free to open an issue. Bug reports help make sure the problem doesn't carry over into the new version.
- **Share ideas and feature requests:** Open an issue to describe what you have in mind. Ideas can still be considered for the new version.
- **Wait for the release:** Once the new version is out, this file will be updated with contribution guidelines – and pull requests will be welcome again.

Thanks for your patience and for supporting the project!
